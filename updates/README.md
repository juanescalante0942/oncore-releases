# Oncore update feeds

Public signed release metadata only. Application source and signing keys remain private.

Mac: 1.8.2; updates are required below 1.8.1.
Windows: 0.9.1; updates are required below 0.9.1.

Changing an unsigned JSON/YAML file does not authorize a release or make it mandatory. The owner must regenerate the signed policy using the private signing key. Clients reject older policy revisions and mismatched installers. Existing apps without this updater need one manual installation.
